# Support

Need help with 360? You're in the right place.

## General Help

For general questions, troubleshooting, account assistance, bug reports that do not involve security, or other help with 360, contact:

**help@360-search.com**

Please include enough information for us to understand the issue, such as:

* What you were trying to do
* What happened
* What you expected to happen
* Your 360 version, if applicable
* Your operating system or device, if relevant
* Steps to reproduce the issue
* Screenshots, logs, or other useful details, if available

Do not send passwords, API keys, authentication tokens, or other sensitive information unless it is specifically necessary and requested by a maintainer.

## GitHub Issues

Use GitHub Issues for reproducible bugs and feature requests that belong in the project.

Before opening an issue:

* Search existing issues for duplicates.
* Make sure the issue is not a security vulnerability.
* Include the relevant details needed to reproduce or understand the issue.

For larger changes or major features, review [CONTRIBUTING.md](CONTRIBUTING.md) before opening an issue or Pull Request.

## GitHub Discussions

Use [GitHub Discussions](https://github.com/360DigitalCo/360/discussions) for questions, ideas, general discussion, and topics that do not fit well in an issue.

## Security Issues

Do **not** report security vulnerabilities through a public GitHub issue or general support channel.

Please follow the project's [Security Policy](SECURITY.md) and report security vulnerabilities privately to:

**admin@360-search.com**

If you are unsure whether an issue is security-related, review [SECURITY.md](SECURITY.md) or contact the security and administration address privately.

## Community

You can also join the [360 Discord Community](https://discord.gg/sgPPtYKRw) for community support, discussions, announcements, and project updates.

## Contributing

If you want to help improve 360, see [CONTRIBUTING.md](CONTRIBUTING.md) for contribution guidelines, issue reporting, and Pull Request requirements.

Thank you for using and supporting 360.
