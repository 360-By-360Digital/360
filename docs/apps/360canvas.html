360Canvas

Site builder for creating and publishing sites from 360.

Overview

360Canvas is the visual site builder in the 360 app collection. It lets signed-in users create sites, add pages and blocks, edit content, and publish a site.

Sites

Your sites are listed after signing in. A new site can be created from the dashboard and opened in the builder.

Pages

Pages can be added from the builder. Each page can contain its own set of blocks and content.

Blocks

The builder includes blocks for headings, buttons, images, links, and columns. Content is edited in the builder before saving.

Publishing

A site can be published or unpublished from the site controls. Published sites can use a 360-search.com subdomain or a configured custom domain.
