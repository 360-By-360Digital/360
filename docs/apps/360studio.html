360Studio

A management interface for 360Vids and 360Music content.

Overview

360Studio is the management area for media published through 360Vids and 360Music.

Content

The dashboard groups content from Vids and Music and requires sign-in to manage it.

Editing

Media entries can be edited and thumbnails can be changed where supported.

Deletion

Delete controls are available for removing managed content. Use them carefully because the action changes the stored item.
