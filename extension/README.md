# 360 New Tab Chrome Extension

This extension replaces Chrome's New Tab page with the live 360 home screen.

## Install in Chrome Developer Mode

1. Extract the project ZIP.
2. Open `chrome://extensions`.
3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select the **`extension`** folder inside this project.
6. Open a new tab with `Ctrl+T`.

The extension redirects the New Tab override to the live 360 home page at `https://360-search.com/`.
