# Contributing to 360

First off, thank you for your interest in contributing to **360**! 🎉

360 is an open-source project developed by **360Digital, Co.** We welcome contributions from developers of all experience levels. Whether you're fixing a typo, improving documentation, optimizing performance, or adding a new feature, your help is appreciated.

---

# Before You Start

Before opening a Pull Request, please:

* Search existing issues to avoid duplicate work.
* Open an issue first for large features or major changes.
* Keep Pull Requests focused on a single topic whenever possible.
* Test your changes before submitting.

---

# Contribution Guidelines

Please follow these basic guidelines:

* Write clean, readable, and maintainable code.
* Follow the existing project style and structure.
* Remove unused code before submitting.
* Use meaningful commit messages.
* Avoid unnecessary dependencies.
* Ensure your changes do not intentionally break existing functionality.
* Respect the project's license (GNU AGPL v3.0).

---

# Pull Requests

When submitting a Pull Request:

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes.
4. Test everything thoroughly.
5. Submit a Pull Request with a clear description.

Please include:

* What changed
* Why it changed
* Screenshots (if applicable)
* Steps to test your changes

Maintainers may request changes before merging.

---

# Becoming a Contributor

If your Pull Request is accepted, you may request to be listed in the project's **Credits** section within the README.

To do so, simply include the following in your Pull Request description:

> I'd like to be listed as a contributor in the README.

Maintainers reserve the right to determine the placement and wording of contributor acknowledgements.

---

# Reporting Bugs

When reporting a bug, please include:

* Operating System
* Browser (if applicable)
* Version of 360
* Steps to reproduce
* Expected behavior
* Actual behavior
* Screenshots or logs (if available)

---

# Feature Requests

Feature requests are always welcome.

Please explain:

* The problem you're trying to solve.
* Your proposed solution.
* Any alternatives you've considered.

---

# Code of Conduct

Please be respectful and constructive when interacting with other contributors.

Harassment, discrimination, personal attacks, spam, or intentionally disruptive behavior will not be tolerated.
